# 🦑 AgentPoker — 德州扑克 · 现金局 · 锦标赛 · 鱿鱼场

**[English](README.en.md)** | 中文

纯原生 JS 的单页德州扑克游戏(2D 牌桌渲染),无构建步骤、无后端,打开即玩。中英双语。

**在线游玩**: https://xyzach.github.io/AgentPoker/

## 功能

### 三种模式
- **现金局** — 盲注固定,输光随时重买,可随时离座结算盈亏
- **锦标赛** — 盲注逐级上升(12 级盲注表+前注),打到只剩一人,前三名 50%/30%/20% 分奖
- **鱿鱼场 🦑** — 锦标赛 + 鱿鱼机制:
  - **淘汰时钟**: 每 N 手强制淘汰场上最短码(筹码直接进小猪罐)
  - **击倒赏金**: 淘汰对手立即获得买入一半的赏金筹码
  - **最终摊牌**(可选硬核规则): 时钟到点的那一手全员强制全下
  - 奖池可视化: 金币飞进悬吊的小猪存钱罐 🐷

### 专业牌桌机制
无限注 Hold'em 完整规则: 盲注/前注/单挑特殊规则、最小加注、不完整全下不再开下注、
**边池精确计算**(含弃牌死钱下沉)、平分底池余 chip 处理、同时出局按码量排名。

### 每局复盘
可开启"每局复盘": 每手结束询问是直接下一局还是先复盘——
查看所有人底牌(含弃牌者)、成牌、盈亏与逐街动作时间线。

### 记牌器
52 张牌实时追踪: 你的手牌(蓝)/公共牌(绿)/亮出的弃牌(红)。
开启"亮出弃牌"后,弃牌死牌会从胜率模拟中剔除。

### 实时胜率
蒙特卡洛模拟(~2200 次/次更新,分块计算不卡帧),显示胜/平/负概率、
底池赔率对比("值得跟/跟注亏")、当前成牌牌型。全下 runout 时显示各家实时赢率条。

### 六种 AI 风格
紧凶(TAG) / 松凶(LAG) / 紧弱(Rock) / 松弱(Fish) / 均衡(Balanced) / 疯狂(Maniac)。

AI 决策 = **风格参数 × 蒙特卡洛胜率 × 底池赔率 × 位置 × 随机噪声**,
含短码 push/fold、半诈唬、鱿鱼时钟压力下的求生模式。每局 AI 还有随机"心情"微调。

### 大模型接入
支持任意 OpenAI 兼容接口(DeepSeek / 智谱 GLM / Moonshot / 通义 / OpenAI / 自定义):
- 轮到你时点击 **🤖 AI 建议** 获取决策建议(动作+理由+置信度,一键采纳)
- 人机玩家按可调比例咨询大模型,与风格算法加权融合(可调话语权)
- 配置仅存本地浏览器,不上传任何服务器

### 中英双语
大厅/游戏内/复盘/结算全部文案支持中英切换,默认中文,选择会被记住。

### 其它
2D 牌桌 DOM/CSS 渲染(座位顺时针、铭牌自动避让布局);
WebAudio 合成音效(发牌/筹码/淘汰/鱿鱼警报);0.5×~4× 变速;快捷键 F/C/R/A/D。

**公平性**: AI 与建议只使用公开信息+自身手牌,绝不读取牌堆。

## 技术
- 纯原生 JS,无构建、无框架、零依赖;DOM/CSS 2D 牌桌 + 自研补间动画
- 牌力评估器: 位运算 7 张直评; 引擎事件驱动, 与渲染完全解耦
- i18n: key=中文原文单向映射 EN 字典, `PK.t()` + `data-i18n` 静态替换
- `tests/run-tests.js`: 308 项 Node 测试(评估器/胜率基准/三模式 fuzz/每手资金对账/边池守恒/鱿鱼时钟/复盘快照)
- `tests/check-i18n.js` / `tests/check-ids.js`: 字典完整性与 DOM ID 引用静态检查
